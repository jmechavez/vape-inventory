# 🚀 Vape Inventory Management System

A full-stack inventory management system designed for tablet-first use on iPad Safari, built with **Go** backend and **React + TypeScript** frontend.

---

## ✨ Features

### Core Features
| Feature | Description |
|---------|-------------|
| 📊 **Dashboard** | Real-time sales and inventory overview with animated counters |
| 📦 **Products** | Manage product catalog with SKU, pricing, and margin tracking |
| 📈 **Inventory** | Track stock levels, movements, and receive/damage/adjust stock |
| 💰 **Sales** | Create sales with cart, multiple payment methods, and receipt printing |
| 📋 **Sales History** | Filter and search past transactions with date/payment filters |
| 🏢 **Suppliers** | Manage supplier information and contact details |
| 📊 **Reports** | Sales performance analytics (Coming Soon) |

### UI/UX Highlights
| Feature | Description |
|---------|-------------|
| 📱 **Tablet-first** | Optimized for iPad 10th/11th Generation |
| 👆 **Touch-friendly** | 44px+ touch targets for comfortable interaction |
| 🍃 **Safari-optimized** | Safe areas, viewport fixes for iPad Safari |
| 🌙 **Consistent Design** | Unified design system across all pages |
| ♿ **Accessible** | ARIA labels, focus states, keyboard support |
